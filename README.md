# ∫ Calculus Quest

A browser game that teaches **beginner calculus** through short lessons and play.
No install and no internet needed: just open `index.html` in any web browser.

## How it plays

Each world opens with a short lesson from Professor Owl, followed by 6 questions.
You get **3 hearts** per world. Clear a world to unlock the next one and add a formula to your **Formula Notebook**.

| World | Topic | What students practise |
|---|---|---|
| ⛰️ Slope Valley | Rate of change | rise ÷ run, slope sign, `y = mx + b`, average speed |
| 🌊 Limit Lake | Limits | plugging in, tables for 0/0, holes in graphs, limits at ∞ |
| 🗼 Tangent Tower | Derivative as slope | drag a slider to find the tangent line, secant → tangent, flat tangents |
| 🥋 Derivative Dojo | Derivative rules | power rule, constants, polynomials, f′(a) |
| 🏝️ Area Archipelago | Integrals | area under a curve, Riemann sums, antiderivatives, Fundamental Theorem |
| 🐉 Final Boss | Mixed review | 10 questions drawn from every world |

### Game features
- **Fresh questions every time**: each question is generated at random, so replays never repeat exactly.
- **Interactive graphs**: after each answer the graph reveals the idea (rise/run triangles, tangent lines, exact area).
- **Hints** (💡) with an explanation after every answer, including why the common wrong answers are wrong.
- **XP, streaks 🔥 and up to 3 stars** per world (3 stars = no mistakes).
- Progress is saved in the browser. Keyboard shortcuts: `1`–`4` to answer, `Enter` for next.
- Works on phones and has a light/dark theme.

## Run it
- **Locally:** double-click `index.html`.
- **Online:** turn on GitHub Pages for this repository (Settings → Pages → deploy from branch, root folder) and share the link with students.
